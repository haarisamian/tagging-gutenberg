# LLM Tagging Analysis

This repo contains data, scripts, and notebooks for comparing LLM-based character tagging methods (`whole`, `chunked`, `separate`) against Sharon’s manual annotations of *Pride and Prejudice*.  

Includes datasets, model outputs, and analysis plots for evaluation and visualization.  

To reproduce results, install dependencies via `requirements.txt` and run `llm_tagging.py` or open the notebooks.
